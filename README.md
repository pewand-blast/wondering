# Wondering CMS

Sanity Studio for the Wondering website, based on the current Figma `Final` page.

## Run locally

```bash
npm install
npm run dev:3334
```

The Studio runs at `http://localhost:3334`.

Set the real Sanity project values in `.env`:

```bash
SANITY_STUDIO_PROJECT_ID=your-project-id
SANITY_STUDIO_DATASET=production
```
